# かお からだ あそび 仕様（kao-karada-asobi）（第5版 2026-11-05）
第5版：段階D（見本をうすくする）と段階E（見本なし）を実装した内容を反映した（3、11）。これで、書籍 7-2 の「見本にマッチング → ひとりで構成」の流れがそろった。第4版：段階B（見本に重ねる）と段階C（身体）、顔のことばの拡張（みみ・まゆ）を実装した内容を反映した（11の実装メモ）。第3版までは、他のAI（ChatGPT・Gemini）の意見と、作成者の決定（9）を反映した。

## 0. 設計思想（開発中の判断基準）
- 教材として作る。ゲームとして完成させることが目的ではない。
- 子どもが、見本や言葉を手がかりに、身体の部分を見つけ、選び、その場所に自分で置く。成功の基準は「その部分を正しい場所に置けたこと」。
- 身体の部分の名前は、遊びの中で聞いて、指さして、置いて、覚える。文字は子どもの画面に出さない（言葉は声で伝える）。
- 迷ったら「子どもが見本や言葉を理解して、自分で判断する場面が残っているか」で決める。
- 「語彙の理解（指さし）」と「構成（置く）」は、別々の力。混ぜずに、別の段階として扱う。

## 2. 対象と目的
- 対象：年長児。
- 目的
  1. 顔・身体の部分を、見本どおりの場所に置く（構成）。
  2. 身体の部分の名前と場所を理解する（基礎語彙）。
  3. 指示（「めは、どこ？」）に応じて、その部分を指さす（言葉と身体の対応）。
- 子どもが話すことは求めない（発語を必須にしない）。聞いて、わかって、指さす・置く、までを目標にする。名前を言えなくても、聞いて理解して指させれば、できたと見る。

## 3. 段階（支援者メニューで選ぶ）
| 段階 | 内容 | 手がかり | 見る力 | 状態 |
|---|---|---|---|---|
| A 指さし | 名前を聞いて（声）、人の絵の中の、その部分を指さす・タップする | 言葉 | 語彙の理解 | **実装済み**（顔・身体） |
| B 見本に重ねる（顔） | 顔の見本（うすい点線の輪）に、部品を持っていって置く | 見本の図・形・位置 | 構成 | **実装済み** |
| C 見本に重ねる（身体） | 身体の見本（うすい点線の形）に、部品を置く | 見本の図・形・位置 | 構成 | **実装済み** |
| D 見本をうすくする | 見本の図を、うすい点線（Bの約35%）にして置く | 見本（うすい）・形・言葉 | 構成＋記憶 | **実装済み** |
| E 見本なし | 見本を出さず、子どもが、部分の位置を考えて置く | 言葉・部分どうしの位置 | 構成（自立） | **実装済み** |

- 進め方：A → B → C → D → E。A は、いつでも単独で使える（語彙の練習だけ）。
- 「耳はどこ？」と聞いて指すこと（A）と、部品を正しい場所に置くこと（B〜E）は、別の力。A ができても、B 以降ができるとは限らない（逆もある）。支援者が、どちらでつまずいているかを分けて見られるようにする。
- 左右のある部分は、左右を区別しない（どちらの場所に置いても正解）。**絵も、左右で同じ形にする**（左右の目・みみ・まゆ・うで・あしは、同じ部品。置くときは、空いている近い方の場所に入る）。

### 段階D・E（見本をうすくする・見本なし）の遊び方（2026-11-05 実装）
- 置く仕組み（持つ・置く・戻る・左右の同じ部品・手助けの範囲）は、B・Cと同じ。違いは、見本の見え方だけ。
  - **B**：見本（点線）が、はっきり出る。
  - **D**：見本が、Bの約35%のうすさで出る。見本を見ながら、記憶も使う。
  - **E**：見本は出さない。人の絵には、置いていない部分の場所が空いて見える。子どもは、ことば（部品を持つと名前が聞こえる）と、部分どうしの位置（めの下にはな、など）を手がかりに置く。
- Eでは、手助け「大きい」でも、いつもうっすら光る補助は出さない（待ったときのヒントだけ）。ヒント「出す」で、待つと次に置く場所が光る。
- 正しい場所なら、見本に収まり、ことんと鳴り、星が出る。違う場所は、音も示しもなく置き場へ戻る（B・Cと同じ）。ぜんぶ置けたらお祝い→次の問い。
- 段階の進め方：B → D → E。手がかりを、少しずつ減らす。

### 見る絵と、ことば（支援者メニューで選ぶ）
| 見る絵 | ことば | 部分 |
|---|---|---|
| 顔（基本） | め・はな・くち | 部品4（め2・はな・くち） |
| 顔（ひろげる） | ＋みみ・まゆ | 部品8（＋みみ2・まゆ2） |
| 身体 | あたま・おなか・うで・あし | 部品6（あたま・おなか・うで2・あし2） |
- 身体の部品の名前は、子どもに身近な言葉にそろえた：どう→「おなか」、うで（て を含む）、あし。て・足先を分ける版は、これから。
- 触れられる部分の数：2／すべて。2のときは、ことばの中から毎回かわる2つを、うすい輪で示す。輪のない部分は、触れても反応しない。
- まゆは目に近いので、手助け「大きい」のときは、目とまゆを間違えやすい。ことばを「ひろげる」にするときは、手助けも見直す。
- 関節など（ひじ・ひざ・かた・ゆび）は、これから。かみ（髪）は、部品にしない（絵の飾りとして描き、色を選べる）。

### 段階B・C（見本に重ねる）の遊び方
- 絵の見本は、うすい点線（顔は輪、身体は部分の形）で出る。部品は、画面の下の置き場に並ぶ。
- 子どもが部品を持って、見本の場所に置く。正しい場所なら、見本に収まり、「ことん」と音が鳴り、星が出て、「め（だね）」と声が出る。違う場所に置いたときは、音も示しもなく、置き場へ戻る。
- 持った部品は、もとの大きさになる（置き場では、入りきらないとき小さく並べる）。
- 置く範囲は、手助けで変える（大きい／ふつう／小さい）。ヒントは、次に置く場所を光らせる。
- 全部置けたら、お祝い（強さは支援者が選ぶ）。新しい見本へ。

## 4. 画面（子どもの画面は文字なし）
- 人の絵（顔・身体）を、画面の中央に出す。
  - 案A（2026-11-03 採用）：平らな色だけ。線は細く、髪は二色（うしろは少し暗く、前髪は明るい）、輪郭はあごに向かってすぼまる、目は丸い点（小さな白いつや）、まゆは細い線、はなは小さな線、口はやさしい線。影・光沢・ほほの赤みは使わない。性別を感じさせない、左右対称の人。髪の初期値は明るい茶。まゆ・みみは、ことばに入れないときは飾り（触れても反応しない）。
  - 身体（段階A・C）：シャツ（やさしい緑）とズボン（やさしい青）、くつ。うで・あしは、まっすぐ下げた、左右対称の形。頭には、顔と髪を簡単に描く。
  - 表情は、穏やかなままで変えない（表情の理解は別の課題）。
  - 身体は、シャツとズボンを着た状態の輪郭にする。下着・性差を示す部分は描かない。
  - 肌の色と髪の色を、それぞれ3種類から、支援者が選べる（初期値は、やさしい肌色・黒〜茶の髪）。
- 指さし（段階A）：聞かれた部分をタップすると、その部分が金色に光り、「ことん」と音が鳴り、星が出る。違う部分をタップすると、白い光が静かに消えるだけ（音・揺れ・×は出ない）。答えたあとの連打は無視する。
- 全部の問いに答えたら、お祝い（強さは支援者が選ぶ）。新しい問いへ。
- 部品を置く段階（B以降）は、見本に重ねる仕組み（くみたて あそびと同じ考え方）を使う。違う場所では、静かに置き場へ戻る。

## 5. 声（読み上げ）
- 端末の読み上げ機能で、問い（「めは、どこ？」）と、答えたあとの一言（「めだね」）を話す。支援者や保護者が、声を出しにくいときも使えるようにする（2026-11-03 決定）。
- 既定は、声「中」・速さ「ゆっくり」。**声は、支援者メニューの「声の大きさ」で、なし／小／中／大に変えられる**。機械の声が苦手な子・聴覚が敏感な子には、「なし」にして、大人の声で行う。
- 「もういちど声で聞く」ボタン（画面の下・支援者メニュー）で、問いをもう一度話す。「声をためす」で、端末の声を確かめられる。
- 日本語の声が端末にないとき・読み上げが使えない端末のときは、支援者メニューに、その旨を出す。
- 子どもの声は録音しない。マイクは使わない。名前の読み方は、ひらがなで統一する。

## 6. 手助け（みんな共通）
はめ あそび・くみたて あそびと同じ考え方。入る範囲（触れられる範囲）と、見た目の補助の両方を変える。
- 大きい：触れられる範囲が広い（1.7倍）。聞かれた部分が、はじめから、うっすら光る。4秒たつと、光が強まる。
- ふつう：少し広い範囲（1.15倍）。10秒たつと、聞かれた部分が光る。
- 小さい：範囲が小さい（0.85倍）。光らない。ヒントは、支援者が出したときだけ。
- ヒント：出す／出さない。「ヒントを今出す」で、聞かれた部分を光らせる。

## 8. 他のAIの意見と、仮決定（2026-11-03）
ChatGPT と Gemini の意見は、ほぼ同じ方向だった。一致した点は仮決定とした。
| 項目 | 仮決定 |
|---|---|
| 名前の出し方 | 声で出す。大人の声（声「なし」）も使える（5を参照） |
| 指さしの順番 | 顔の主要（め・はな・くち）から。周辺・身体は、あとで足す |
| 似た部分の混同 | 最初は2つ。判定の範囲は、手助けで変える |
| 左右 | 区別しない |
| 人の絵 | 平らで中性的。表情は固定。肌・髪の色は3種類から選ぶ |
| 服・配慮が要る部分 | シャツとズボンの輪郭。配慮が要る部分は含めない |
| 実物教材 | アプリで構成のイメージを作り、磁石などの実物教材へ橋渡しする |

- 実物との使い分け（支援者向けの説明に書く）：アプリは、手がかりを少しずつ減らす難しさの調整と、すぐに返事が返ってくることが得意。磁石などの実物は、指先の細かい動きや、手ざわり、実際の空間の感覚が得意。アプリで見本どおりにできるようになったら、実物でもやってみる。

## 9. 決定事項（2026-11-03）
1. 紙の観察欄は、印刷できるようにしない。観察は、支援者が自分の紙に書く（案A）。
2. かみ（髪）は、部品にしない。
3. 最初の版は、顔の主要な3つ（め・はな・くち）で確かめ始める（基礎語彙の範囲で十分）。
4. 音声読み上げ「いう」は、最初の版に入れる（支援者・保護者が話せない場合があるため）。
5. シール人形との分け方は、最初の版では書かない。
6. 観察は、指さし（語彙の理解）と、置く（構成）を分けて見る。
7. 左右で同じ見た目の部品は、同じ部品として扱い、どちらの場所に置いても正解にする（目を、左の部品・右の部品に分けない）。
8. 段階B・Cは、顔の指さしの次に実装する。ことばの拡張（みみ・まゆ）と身体は、同じ仕組みの上に足す。

## 10. 約束（他のアプリと同じ）
- 子どもの名前・記録・声・顔・録音・写真は保存しない。カメラ・マイクは使わない（子どもの声は録音しない）。
- 子どもの画面に文字を出さない（支援者用の説明画面にだけ文字）。点滅なし。音はやわらかく、音量は支援者が調節。
- 治療効果をうたわない。
- 観察は、アプリには残さない（支援者が紙に書く）。見るところ：
  - 語彙（A）：名前を聞いて、その部分を指さすか。似た部分を間違えるか。間違えたとき、自分で直すか。
  - 構成（B〜E）：見本を見てから置くか。違う場所に置いたとき、自分で置き直すか。見本をうすくしたら、どこまで置けるか。
- 画面の向きが変わっても、いまの問いと進み具合は残す。

## 11. 実装メモ
- public/index.html 単一ファイル。はめ・くみたての、音・お祝い・支援者メニュー・とめる／おしまい・紙の背景をそのまま使う。
- 絵は、すべて canvas に描く（外部の画像は使わない）。顔：肌・髪・耳・前髪・め・はな・くち・まゆ・首。身体：あたま（顔と髪つき）・おなか（シャツ）・うで・あし。部分ごとに、見た目の大きさと、触れられる範囲（見た目より少し広い楕円）を持つ。触れられる範囲は、手助けで1.7／1.15／0.85倍に変え、いちばん近い部分を選ぶ。左右のある部分は、どちらをさしても同じ部分。
- 段階Aと段階B・Cは、同じ部分の絵（`glyph`）と、同じ見本の位置を使う。見本の位置は、画面の大きさ・向きが変わるたびに、いまの位置に合わせ直す。
- 段階B・C：置き場の部品（`pcs`）と、見本の場所（`targets`）を分けて持つ。部品が同じ種類の空いている場所のうち、いちばん近いところに入る（左右の目・うで・あしを、取り違えてもよい）。置き場の部品は、入りきらないとき小さくして並べ、持つとき、もとの大きさになる。指のポインターをつかまえるので、画面の外で指を離しても、置き場に戻る。
- 声：speechSynthesis（日本語）。iPad の Safari は、さわったあとでないと話せないので、「はじめる」と画面のタップで準備する。説明画面・メニューを開いている間は、問いも声も進めない。

- 注：コードには段階N（なぞる）・T（さわって聞く）があるが、この仕様書にはまだ書いていない（出典の確認待ち）。
