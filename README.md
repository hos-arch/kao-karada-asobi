# かお からだ あそび (kao-karada-asobi)
参考書籍の「顔・身体の構成」の課題をもとに、身体の部分の名前（基礎語彙）と構成を画面で練習する遊び。対象は年長児。
- `public/index.html` 単一ファイル。Cloudflare Workers（assets）で公開。
- v1：段階A（顔の指さし）。名前を声で聞いて、め・はな・くちを指さす。端末の読み上げを使う（声は なし／小／中／大）。
- 次：見本に重ねて顔をつくる → 身体。
- 失敗の音・揺れなし（光が静かに消える）。成功は「ことん」＋星。手助け 大/ふつう/小。お祝いの強さは調整可。
- 記録・名前・声・顔は保存しない。カメラ・マイク不使用。設計: docs/spec.md
